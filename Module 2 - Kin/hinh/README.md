# Thư mục ảnh — Module 2

Để ảnh biểu đồ export từ Visual Paradigm vào đây (PNG). Tên file theo bảng "Danh sách ảnh cần export" ở đầu [../noi-dung.md](../noi-dung.md).

Module 2 cần đúng **6 ảnh**. Ảnh cũ trong thư mục này đã lạc hậu so với blueprint hiện tại — **vẽ lại toàn bộ**. Bản render tham chiếu của từng blueprint có sẵn ở `ref/`, mở ra đối chiếu khi vẽ.

| Tên file | Biểu đồ | Blueprint |
|---|---|---|
| `m2-uc-chitiet.png` | Biểu đồ UC chi tiết | `../noi-dung.md` mục 1 |
| `m2-trangthai.png` | Biểu đồ trạng thái — phân tích hoạt động | mục 3 |
| `m2-lop-phantich.png` | Biểu đồ lớp phân tích (lớp biên + lớp thực thể) | mục 4 |
| `m2-lop-mvc.png` | Biểu đồ lớp thiết kế (jsp / DAO / model) | mục 5 |
| `m2-hoatdong.png` | Biểu đồ hoạt động — pha thiết kế | mục 6 |
| `m2-tuantu.png` | Biểu đồ tuần tự | mục 7 |

> **Mẫu hình:** UC chi tiết theo **Hình 3.2/3.3/3.4** (không khung hệ thống, có phân cấp actor, UC đăng nhập theo vai trò kế thừa UC `Đăng nhập`); trạng thái theo **Hình 3.9/3.11**; lớp phân tích theo **Hình 3.6**; lớp thiết kế theo **Hình 4.4** (**không vẽ khung package**, tên lớp view kèm đuôi `.jsp`, `DAO` chỉ có `-con : Connection` và `+DAO()`); hoạt động theo **Hình 4.9**; tuần tự theo **Hình 4.10/4.12**.
>
> Giao diện **không cần vẽ và không cần xuất ảnh** — đã trình bày dạng bảng phác thảo xen giữa các bước Kịch bản chính ở mục 2 của [../noi-dung.md](../noi-dung.md).
