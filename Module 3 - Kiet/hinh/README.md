# Thư mục ảnh — Module 3

Để ảnh biểu đồ export từ Visual Paradigm vào đây (PNG). Tên file theo bảng "Danh sách ảnh cần export" ở đầu [../noi-dung.md](../noi-dung.md).

Module 3 cần đúng **8 ảnh**, hiện **chưa có ảnh nào**:

| Tên file | Biểu đồ | Trạng thái |
|---|---|---|
| `m3-uc-chitiet.png` | Biểu đồ UC chi tiết (mục 1) | chưa có |
| `m3-trangthai.png` | Biểu đồ trạng thái — phân tích hoạt động (mục 3, mẫu Hình 3.9/3.11 giáo trình PDF) | chưa có |
| `m3-lop-phantich.png` | Biểu đồ lớp phân tích (mục 4) | chưa có |
| `m3-giaodien-chonchang.png` | Giao diện Chọn chặng (mục 5) | chưa có |
| `m3-giaodien-nhapketqua.png` | Giao diện Nhập kết quả và đối soát (mục 5) | chưa có |
| `m3-lop-mvc.png` | Biểu đồ lớp thiết kế (view / dao / model) (mục 6, mẫu Hình 4.4) | chưa có |
| `m3-hoatdong.png` | Biểu đồ hoạt động — pha thiết kế (mục 7, mẫu Hình 4.9) | chưa có |
| `m3-tuantu.png` | Biểu đồ tuần tự (mục 8, mẫu Hình 4.10/4.12) | chưa có |

> Module 3 có 2 màn hình hiển thị ⇒ 2 ảnh giao diện. Trang `doLuuKetQua.jsp` là trang xử lý, không có ảnh giao diện. Trang chính `gdChinhNV.jsp` là trang chủ chung của hệ thống, không cần mockup riêng.
>
> **Quy tắc tên:** `m<số module>-<tên biểu đồ>.png` — chữ thường, không dấu, ngăn cách bằng `-`. Bảng trạng thái này phải khớp với `docs/00-ke-hoach-va-phan-cong.md` mục 7.
